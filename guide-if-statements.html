If statements

An if statement is a decision. If a condition is true, one block runs. If it is false, the other block runs.

This is one of the most common shapes in programming because real work is full of decisions. 

if (blockedProjects > 0) {
  console.log("Needs attention");
} else {
  console.log("On track");
}

What to notice

  • The condition sits inside the parentheses.
  • The first block runs only when the condition is true.
  • else gives the fallback when the condition is false.

Mental model: an if statement is a fork in the road. The code follows one path or the other.
