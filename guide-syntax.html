Syntax

Syntax is the grammar of code. Braces, quotes, commas, colons, and parentheses show the computer where each piece starts and ends.

If the syntax is wrong, the idea may be correct but the computer still cannot run it. 

function shouldPrioritize(item: Initiative): boolean {
  return item.impact >= 7 && item.effort <= 4;
}

How to read it

  • Read the function name first.
  • Read the input in parentheses next.
  • Read the return line last to understand the rule.
  • Notice that braces wrap the body of the function.

Mental model: syntax is punctuation for computers. It makes your intent readable and valid.
