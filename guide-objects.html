Concept 7 / 8 Objects

Objects

An object groups related facts about one thing. A project, customer, task, or report is usually better represented as an object than as separate loose variables.

Each field has a name, and each name points to one value. 

const project = {
  name: "Sales dashboard",
  priority: "medium",
  blocked: true
};

What to notice

  • project is the object name.
  • name, priority, and blocked are fields.
  • You read a field with dot syntax like project.priority.

Mental model: an object is one record card with several labeled facts on it.
