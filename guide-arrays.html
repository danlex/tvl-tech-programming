Concept 6 / 8 Arrays

Arrays

An array is an ordered list. Use it when you have many values of the same kind, like team members, projects, or tasks.

Arrays help you keep similar data together and then count it, loop over it, or pull one item by position. 

const teamMembers: string[] = ["Diana", "Elena", "Sara"];

console.log(teamMembers.length);
console.log(teamMembers[0]);

What to notice

  • Square brackets mean list.
  • .length tells you how many items are inside.
  • [0] reads the first item in the array.

Mental model: an array is a row of labeled seats. Each item sits in one numbered position.
