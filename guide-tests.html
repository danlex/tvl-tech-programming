Concept 8 / 8 Tests

Tests

Tests are quick checks that confirm whether the code behaves the way you expect.

In this training, tests act like very small examples with pass/fail feedback, so you can tell whether the rule works. 

assert(
  shouldPrioritize({ name: "Sales dashboard rollout", impact: 9, effort: 3 }) === true,
  "Expected strong work to return true"
);

What to notice

  • The first part is the condition being checked.
  • The message explains what should have happened if the test fails.
  • Good tests describe expected behavior, not just technical details.

Mental model: a test is a tiny example with an expected answer attached.
