While loops

A while loop repeats while a condition stays true. It is useful when you want to keep going until something changes.

Loops are good for repetitive work, but something inside the loop must change or it will run forever. 

let openTasks = 4;

while (openTasks > 0) {
  console.log(openTasks);
  openTasks = openTasks - 1;
}

What to notice

  • The condition is checked before each round.
  • The loop stops when openTasks is no longer greater than zero.
  • The line that subtracts one is what makes the loop finish.

Mental model: a while loop is a checklist you keep repeating until the stop condition is reached.
