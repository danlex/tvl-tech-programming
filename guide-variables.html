Variables

A variable is a name for a value. It lets you store something once and reuse it later without rewriting the value every time.

In manager terms, a variable can hold a team name, a blocked status, a project count, or a budget number. 

const teamName: string = "Sales";
const projects: number = 3;

What to notice

  • const creates a variable.
  • teamName is the label you use later.
  • "Sales" is the value stored inside it.
  • : string tells TypeScript what kind of value belongs there.

Mental model: a variable is a labeled box. You put one value in the box and read it again later.
