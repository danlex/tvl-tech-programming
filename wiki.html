Concepts explained in plain language

Use this page like a reference while you work through the lessons. Each guide opens on its own page now, so moving between concepts feels stable and direct.

Variables Store one value under a name. Syntax Read the symbols and structure of code. If statements Make a decision when a condition is true. While loops Repeat work while something stays true. Functions Reuse one step many times. Arrays Keep a list in one place. Objects Group related facts about one thing. Tests Check whether the code behaves as expected.
