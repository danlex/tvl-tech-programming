Functions

A function is a reusable step. It can take input, do some work, and return a result.

Functions matter because they let you name repeatable logic once instead of rewriting it everywhere. 

function makeStatusLine(name: string): string {
  return `Weekly update for ${name}`;
}

What to notice

  • makeStatusLine is the function name.
  • name: string is the input.
  • : string after the parentheses means the function returns text.
  • return sends the final result back out.

Mental model: a function is a named machine. You put something in and get a result back.
